October 14, 2026

WildCatcher 2.2.6 is available

WildCatcher 2.2.6 is available for Windows and macOS. The Windows updater can now retry safely when another app or CLI job is using the installation.

WildCatcher 2.2.6 is now available. On Windows, the updater checks for another WildCatcher instance or CLI job before downloading and restarting. If another process is using the installation, you can finish your other work and retry using the same downloaded update.

Version 2.2.6 is also available for macOS, with support for Apple Silicon and Intel. Find current downloads and full release notes on the official release page.
