野生動物と環境の現場へ

現場の発見を、未来へ。

自然を調べる人の手元に、たしかな記録と使える道具を。調査の積み重ねを、次の判断へつなぎます。

合同会社ReCorta（レコルタ）は、野生動物調査の画像・動画解析ソフトWildCatcherと、環境アセスメント支援ツールWildpassを開発しています。

ReCortaの取り組み

現場を支える、ふたつの道具。

撮影データの確認から、環境アセスメントの記録と報告まで。専門家の仕事に寄り添う製品を開発しています。

01 / WILDLIFE

野生動物の画像・動画解析

提供中 · Windows / macOS

WildCatcher

カメラトラップの大量の画像・動画から動物・人・車両を検出。PC上で結果を確かめ、ラベルを修正し、調査に合わせて出力できます。

Windows 2.2.6 / macOS 2.2.6 · 14日間トライアル

02 / EIA TOOLKIT

EIA・環境アセスメント

開発中 · パイロット検証段階

Wildpass

環境アセスメントの工程、現場記録、根拠資料、チームレビュー、意見対応を一つの案件で整理し、編集できるWord報告書につなぐ業務ワークスペースを開発しています。

開発で大切にしていること

記録を、判断につながる形に。

01

確かめられる記録

データと根拠をたどり、担当者が結果を確認できる流れを大切にします。

02

人が担う専門判断

AIと業務ツールは専門家の仕事を支えるもの。評価や法的な判断を自動で決めません。

03

現場から改善する

利用する人の声と実際の環境をもとに、必要な使いやすさを一つずつ磨きます。
