01 / WILDLIFE ANALYSIS

野生動物の画像・動画解析

提供中 · Windows / macOS

WildCatcher

カメラトラップの大量の画像・動画から動物・人・車両を検出。PC上で結果を確かめ、ラベルを修正し、調査に合わせて出力できます。

  • カメラトラップの画像・動画から動物・人・車両を検出
  • PC上で解析し、結果と種分類を確認・修正
  • CSV・Excelなどの形式へ調査データを出力

種分類やPDF出力など、一部の機能は契約ライセンスにより利用範囲が異なります。

Windows 2.2.6 / macOS 2.2.6 · 14日間トライアル

02 / EIA TOOLKIT

EIA・環境アセスメント

開発中 · パイロット検証段階

Wildpass

環境アセスメントの工程、現場記録、根拠資料、チームレビュー、意見対応を一つの案件で整理し、編集できるWord報告書につなぐ業務ワークスペースを開発しています。

  • 案件の工程、担当、期限と現場の観察・測定を記録
  • 写真・原本資料と根拠を関連づけ、レビュー履歴を残す
  • 編集できるWord報告書へつなぎ、意見対応を整理

Wildpassは実務担当者とのパイロット検証段階です。提供条件や時期はご相談内容と検証範囲に応じてご案内します。

Wildpassは専門家の判断を支えるツールです。法令への適合、種の同定、影響の評価、行政協議や提出手続きを自動で判定しません。
